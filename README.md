Разработка сервиса на основе Clean Architecture
- Реализовала сервис с полностью изолированной бизнес-логикой от внешних интерфейсов.
- Слои: Контроллеры (REST/CLI/Kafka Consumer) → Use Cases → Доменные сущности → Адаптеры (PostgreSQL, Redis, Kafka).
- Единая бизнес-логика одновременно работает через REST API (для веба), CLI и Kafka Consumer (для асинхронной обработки событий).
- Для хранения использовала PostgreSQL и Redis (кэширование).
